# Abitur 2027 Planner

A static, Russian-language study planner for Informatik, Mathematik and Spanisch. The app contains a daily plan, weekly calendar, time records, history and a five-step planning workflow using ordinary ChatGPT conversations.

This repository contains only the reviewed application build, its icons and local runtime library. It contains no study history, personal project URLs, account credentials, backups or private reports.

## Use

Open the GitHub Pages address configured for this repository. On iPhone, open it in Safari, use Share → Add to Home Screen, then open the icon. Load the app once online before using it offline.

Set your own Informatik and Mathematik project links in the app settings. Links are stored only in this browser, separately from study records; there are no accounts or automatic synchronization. Project links must be set again on a new device or a separate browser installation.

## Data and backups

Study data remains in this browser's local storage. Safari and an installed Home Screen app can use separate storage. Export a full backup before changing device, address or browser, clearing website data, or reinstalling the app. Import the backup in the destination and check the restored records. The app does not upload data or use AI APIs, analytics, cloud databases or trackers.

Local storage can be cleared by the browser or operating system. Offline caching is not a substitute for a downloaded backup. GitHub hosts the static files and can process normal web-server access data.

## Updates

A new app version waits for older app tabs to close. Save your current work, close all planner tabs/windows and reopen. Existing local study records are kept; export a backup before larger changes.
